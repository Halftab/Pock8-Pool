# Pock8 Pool 🎱

A lightweight, browser-based pool game with Solo and Pass & Play modes, plus an Android APK build.


## Game modes

- **Solo** — play a solo challenge and track your run statistics. Only wins contribute to the historical best records; a lost run's statistics are still shown on its end screen.
- **Pass & Play** — take turns with another player on the same device. Players are assigned solids or stripes, and the 8-ball is the final ball.


## Controls

- Use touch or mouse interaction on the table to aim and take shots.
- Drag back from the cue ball to set shot direction and power, then release to shoot.
- Use the on-screen controls for pause, options, and starting or resetting a game.
- In Pass & Play, players take turns on the same device.


## Android installation

1. Open the [Pock8 Pool v1.0 release](https://github.com/Halftab/Pock8-Pool/releases/tag/1.0).
2. Download `app-debug.apk` to your Android device.
3. Open the downloaded APK and follow Android's installation prompts. If Android asks, allow installation from that source.
4. Launch **Pock8 Pool**.

Android may display a warning because this APK is a debug build rather than a Play Store release.
